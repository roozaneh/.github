## ✨ مزایا و تعهدات فنی روزنه نت

1. **تست رایگان ۳ روزه (۲ تا ۳ گیگابایت):** ارزیابی واقعی سرعت و پینگ پیش از پرداخت از طریق ربات رسمی.
2. **قانون انتقال ۱۰۰٪ حجم باقیمانده (<bdi>Data Rollover</bdi>):** با تمدید پیش از پایان موعد، تمام حجم مصرف‌نشده به دوره جدید منتقل می‌شود.
3. **جبران خودکار ۲ برابری قطعی (<bdi>2X SLA</bdi>):** در صورت اختلال سراسری تاییدشده بیش از ۳ ساعت، دو برابر زمان قطعی به‌صورت خودکار به اشتراک افزوده می‌شود.
4. **استفاده چندکاربره هم‌زمان (خانوادگی):** قابل استفاده روی موبایل و دسکتاپ با رعایت سیاست مصرف منصفانه در تمام پلن‌ها.
5. **۵ لوکیشن فعال اختصاصی:** آلمان (<bdi>Germany</bdi>)، هلند (<bdi>Netherlands</bdi>)، انگلیس (<bdi>UK</bdi>)، آمریکا (<bdi>USA</bdi>) و ترکیه (<bdi>Turkey</bdi>).
6. **تمدید ۱۰۰٪ دستی و ضمانت عودت وجه ۲۴ ساعته:** بدون کسر وجه خودکار، همراه با [مرکز شفافیت و حریم خصوصی](https://roozaneh.github.io/v2ray-clients-download/privacy.html) و [شرایط استفاده (<bdi>SLA</bdi>)](https://roozaneh.github.io/v2ray-clients-download/terms.html).
